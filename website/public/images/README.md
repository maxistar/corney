# Corney website images

`corney-choc.webp` derives from `../../../docs/corne.jpg`; `corney-mx.webp` derives from
`../../../docs/cornemx.jpg`. Both source photographs belong to this repository. Public variants
were converted with ImageMagick `-auto-orient -strip -resize '1200x900>' -quality 82`, removing EXIF,
including location and camera information.

The alt descriptions live in `src/data/project.js`. There is currently no public photograph of the
dongle OLED or an installed trackpad; the site uses text and diagrams for those features.
